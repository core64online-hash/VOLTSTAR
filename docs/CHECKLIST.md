## Phase 7 — Готовність до релізу
- [x] Безпека: ліміти частоти запитів (вхід за IP і email, реєстрація, скидання паролю, заявки, оформлення, пошук замовлення гостем; загальний ліміт), захисні заголовки API (сувора CSP, X-Frame-Options, HSTS у prod) і web (CSP з обмеженням `form-action` платіжними шлюзами), ліміт розміру тіла, Swagger у prod лише явно, `trust proxy`
- [x] Секрети: API не стартує в production з дефолтним/коротким `JWT_SECRET`, http-адресами, `*` у CORS, sandbox-оплатами чи вимкненими лімітами
- [x] CSRF: токен у заголовку `Authorization` (не cookie) — класичний CSRF неможливий; вебхуки перевіряються підписом
- [ ] Перенесення токена з localStorage в httpOnly-cookie + nonce-CSP без 'unsafe-inline' (зменшить наслідки XSS)
- [ ] Спільне сховище лімітів (Redis) для кількох інстансів API
- [x] Продуктивність: індекси під реальні запити (списки замовлень, аналітика за період, воронка, ретеншн — перевірено EXPLAIN), публічний кеш каталогу в API (лише успішні відповіді), ISR сторінок товару (60 с) і статичний рендер решти сторінок (`setRequestLocale`), розміри зображень проти зсуву макета
- [x] Lighthouse (mobile): головна, каталог, товар, підбір — продуктивність 99–100, доступність/SEO/best practices — 100
- [x] SEO: `sitemap.xml` (усі мови й товари, hreflang), `robots.txt`, canonical + hreflang + Open Graph на публічних сторінках, JSON-LD (Organization, WebSite із пошуком, Product/Offer, BreadcrumbList), noindex для кабінету/кошика/адмінки, справжній 404 для неіснуючого товару, метадані завжди в `<head>`
- [x] i18n uk/en для всіх нових сторінок і метаданих
- [x] Доступність (WCAG 2.1 AA, axe-core): 0 порушень на 10 ключових сторінках — контраст, підписи полів, посилання «до вмісту», видимий фокус, `prefers-reduced-motion`
- [x] Навантажувальні тести: `node scripts/load-test.mjs` — 8 сценаріїв (каталог, пошук, товар, фасети, підбір, SSR каталогу й товару, оформлення) з порогами p95 і помилок < 1%
- [ ] Навантаження проти staging із продакшн-обсягом даних і CDN (локальний прогін — одна 4-ядерна машина з усіма сервісами)
- [x] Бекап і відновлення БД: `scripts/db-backup.sh` (ротація, контрольна сума), `db-restore.sh`, `db-verify-restore.sh` (відновлення в тимчасову БД і звірка таблиць) — перевірено
- [x] Політики: сторінка політики конфіденційності (uk/en, шаблон — перевірити юристу), банер згоди з повторним вибором із футера, посилання на політику у формах
- [x] Права субʼєкта даних: вивантаження своїх даних (JSON) і видалення акаунта (знеособлення профілю, CRM-контакту й заявок; замовлення лишаються для обліку)
- [x] Строки зберігання: `pnpm --filter @voltstar/api data:retention [--dry-run]` — кошики, заявки без угоди, контакти в старих B2C-замовленнях, журнал, токени, вебхуки
